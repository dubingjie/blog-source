# 9.15日笔记

## 一、知识点

### 【1】IIS 建网站

IIS 是什么？

打个比方：

- 浏览器访问网站 = 客人来餐厅点菜
- IIS = 餐厅的 前台服务员 ，负责接待客人、把菜（你的网页文件）端出去
- 网页文件 （html、图片等）= 后厨的菜
没有 IIS（服务员），别人访问你的 IP 时就没人接待，什么都拿不到。



**本机 IIS vs 远程服务器：**

|          | 本机 IIS                      | 远程服务器   |
| -------- | ----------------------------- | ------------ |
| 餐厅位置 | 自己家里                      | 机房         |
| 谁能来吃 | 自己（localhost）或同一局域网 | 全世界任何人 |
| 营业时间 | 电脑开机营业                  | 24 小时营业  |
| 门牌号   | 内网 IP ，外面找不到          | 公网 IP      |
| 费用     | 免费                          | 租金         |



常见的几种“远程”形式：

- 云服务器（ECS/CVM） ：租一整台虚拟电脑，你远程登录，想装 IIS、Nginx 都行——和操作本机一模一样
- 虚拟主机 ：商场里只给你一个“档口窗口”，只能传网页文件，不能装软件，便宜但受限
- 云平台/托管（如 Vercel、Gitee Pages） ：连档口都不用管，把代码一交，平台帮你“摆盘上菜”
