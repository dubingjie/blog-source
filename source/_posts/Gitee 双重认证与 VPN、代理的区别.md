### 【2】VPN 和代理 

#### 一、核心区别

| 对比项       | 代理（Proxy）                    | VPN                             |
| :----------- | :------------------------------- | :------------------------------ |
| **工作层级** | 应用层为主                       | 网络层/系统层                   |
| **影响范围** | 只影响设置了代理的软件           | 整台设备所有流量                |
| **加密**     | 通常不加密，或只加密到代理服务器 | 全程加密（客户端到 VPN 服务器） |
| **主要目的** | 隐藏 IP、绕过限制、缓存加速      | 加密通信、远程接入内网、隐藏 IP |
| **典型协议** | HTTP、HTTPS、SOCKS5              | OpenVPN、WireGuard、IPsec、L2TP |
| **速度**     | 通常较快（不做加密）             | 略慢（需加解密）                |
| **配置位置** | 浏览器/软件里填代理地址          | 系统网络设置里建连接            |

#### 二、代理（Proxy）

**工作原理：**

1. 软件把请求发给代理服务器
2. 代理服务器替你去访问目标网站
3. 目标网站看到的是代理服务器的 IP
4. 代理把结果返回给你

**特点：**

- 只代理指定软件，其他软件仍直连
- 默认不加密
  - HTTP 代理：能看到明文内容
  - HTTPS 代理：只能看到域名，看不到具体内容
- 常见类型：
  - HTTP/HTTPS 代理：主要给浏览器用
  - SOCKS5 代理：更通用，能代理各种流量，但不加密
  - 反向代理：用在服务器端

#### 三、VPN

**工作原理：**

1. 设备与 VPN 服务器建立加密隧道
2. 所有网络流量都走这条隧道
3. 出口是 VPN 服务器的 IP
4. 中间人只能看到你连了 VPN，看不到具体内容

**特点：**

- 全局生效，整台设备流量都走 VPN
- 全程加密（设备到 VPN 服务器）
- 常见用途：
  - 远程接入公司内网（企业 VPN）
  - 公共 Wi-Fi 上保护隐私
  - 跨地区访问

#### 四、比喻理解

- **代理**：找朋友代收快递。朋友替你去拿，商家看到的是朋友地址。但朋友拿到后怎么给你、路上会不会被看到，取决于交接方式。
- **VPN**：你和家之间修了一条专用加密隧道。所有东西都从隧道走，外面的人看不到里面运的是什么。

#### 五、使用场景选择

| 需求                       | 选择                 |
| :------------------------- | :------------------- |
| 只想让浏览器换 IP          | 代理                 |
| 整台电脑所有流量加密/换 IP | VPN                  |
| 远程连公司内网             | 企业 VPN             |
| 公共 Wi-Fi 保护隐私        | VPN                  |
| 某些软件不支持代理设置     | VPN 或系统级代理工具 |

#### 六、一句话总结

> **代理是“按软件转发”，VPN 是“整机加密隧道”。**
> 代理轻量但不加密、范围小；VPN 全局、加密，但稍重。两者用途不同，不是谁替代谁。

#### 七、易混淆点提醒

1. **代理 ≠ 加密**：普通代理不加密，别把它当隐私工具。
2. **VPN ≠ 翻墙专用**：企业远程接入才是 VPN 的本职。
3. **虚拟机网络模式 ≠ VPN/代理**：
   - NAT/桥接决定虚拟机怎么接入网络
   - VPN/代理决定流量怎么转发和加密
4. **远程桌面走不走代理/VPN**：取决于代理是否覆盖该软件，VPN 则默认全局覆盖。
